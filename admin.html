Accounts and charts

Every account, its charts and its chart allowance. Only admins can see this page.

Delete chart

Deletes this chart and everything linked to it. The user can create a new chart.

Reset allowance

Keeps all charts. Lets the user create a new chart again.

Delete all data

Deletes all of this user's charts, chats and reports. Their login stays, so they can start fresh.
